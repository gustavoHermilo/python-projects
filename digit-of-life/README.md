#  The Digit of Life (Python)

This Python program calculates the **Digit of Life** from a user's birthdate.

The **Digit of Life** is a numerology concept where the digits of a birthdate are added together to produce a single-digit number that represents a symbolic life number.

---

## Features

- Accepts birthdate in `YYYYMMDD` format
- Converts digits automatically
- Sums all digits
- Reduces result to a single digit (if needed)
- Beginner-friendly Python logic

---

##  How It Works

1. The user enters their birthdate in numeric format (`YYYYMMDD`)
2. The program converts each character into an integer
3. All digits are summed
4. If the result has two digits:
   - The digits are summed again
5. The final value is printed as the **Digit of Life**
