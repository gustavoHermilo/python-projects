#  Letter Finder in Text (Python)

This Python program checks whether **all letters of a word exist inside a given text**, regardless of order or position.

It does **not** search for the word as a sequence — instead, it verifies **character presence**.

---

##  Features

- Case-insensitive comparison
- Checks letter existence only
- Order does not matter
- Simple logic
- Beginner-friendly
- Fast execution

---

##  What This Program Does

Given:
- A **word**
- A **text string**

The program verifies that **every character in the word** appears **at least once** in the text.
