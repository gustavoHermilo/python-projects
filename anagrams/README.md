#  Anagram Detector (Python)

This is a simple Python program that checks whether two texts are **anagrams**.

An **anagram** is when two words or phrases contain the same letters in the same quantity, but in a different order.  
Example:  
`listen` → `silent`  

---

##  Features

- Converts input to lowercase (case-insensitive comparison)
- Sorts letters to compare structure
- Works with words and full sentences
- Simple and beginner-friendly logic

---

##  How It Works

1. The program asks the user to enter two texts.
2. Each text is:
   - Converted to lowercase
   - Converted into a list of characters
   - Sorted alphabetically
3. The sorted lists are compared.
4. If they are equal → **Anagrams**  
   Otherwise → **Not anagrams**
