# Temperature Converter 🌡️

A simple Python program that converts temperatures
between Celsius and Fahrenheit.

## Features
- Celsius → Fahrenheit
- Fahrenheit → Celsius
- Input validation
- Clean and simple structure

## Formulas Used
- °F = (°C × 9/5) + 32
- °C = (°F − 32) × 5/9

## How to Run

```bash
python temperature_converter.py
