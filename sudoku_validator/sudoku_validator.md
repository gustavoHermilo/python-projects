This project is a Python program that validates a completed 9x9 Sudoku board.

The program reads 9 rows of input and checks whether the Sudoku solution is valid according to standard Sudoku rules.

##  Sudoku Rules

A Sudoku board is valid if:

- Each row contains all digits from 1 to 9 exactly once.
- Each column contains all digits from 1 to 9 exactly once.
- Each 3×3 sub-square contains all digits from 1 to 9 exactly once.
