# Alarm Clock ⏰

A simple Python alarm clock that plays an alert
when the current time matches the user-defined time.

## Features
- Uses system time
- 24-hour format
- Input validation
- Simple and clean logic

## Example

Enter alarm time (HH:MM): 07:30  
⏰ ALARM! Time to wake up! ⏰

## How to run

```bash
python alarm_clock.py
