# Tile Cost Calculator 🧱

This Python program calculates the total cost of tiles
needed to cover a floor based on its width, height,
and the cost per square unit.

## Features
- User input validation
- Area calculation
- Cost calculation
- Clean and simple output

## Example

Enter the width of the floor: 5  
Enter the height of the floor: 4  
Enter the cost per square unit: 10  

Floor area: 20.00 square units  
Total tile cost: $200.00

## How to run

```bash
python tile_cost.py
