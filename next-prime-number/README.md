# Next Prime Number 🔢

This Python program continuously generates the next prime number
each time the user presses Enter.

The program stops when the user chooses to quit.

## How it works
- Starts from 2
- Finds the next prime number
- Repeats until user exits

## Example

Press Enter for next prime or type 'q' to quit:
Next prime: 2
Next prime: 3
Next prime: 5
Next prime: 7

## How to run

```bash
python next_prime-number.py
